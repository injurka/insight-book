# Detective English

Динамический игровой плагин InsightBook: расследуй кражу картины в отеле и встречай изучаемые слова в репликах, уликах и собственных фразах.

## Игровой цикл

- Перед делом плагин запрашивает очередь повторения через ctx.api.dictionary.getDueWords('en'). InsightBook возвращает до 50 карточек, назначенных SRS к повторению; для одного дела берутся до восьми наиболее просроченных.
- LLM получает выбранную лексику и создаёт связное дело, показания, контекстные пропуски и улики в проверяемом JSON-формате.
- Игрок проходит пять этапов на каждое слово: узнавание в показании, значение, выбор по контексту, воспоминание показания и собственная фраза.
- После собственной фразы плагин один раз отправляет оценку карточки через ctx.api.dictionary.submitGrade(). В SRS не уходит пять повторных оценок за один игровой проход.
- Проверку собственной фразы выполняет LLM. При временной ошибке сервиса доступна упрощённая проверка наличия целевого слова и длины предложения.

Игровое состояние и улики принадлежат текущему сеансу плагина. Отдельной записи слов или игровых фактов в словарь плагин не делает.

## Разработка

### Реальный InsightBook и HMR

Локальный dev-сервер отдаёт Module Federation remote, который подключается к настоящему InsightBook. Плагин получает слова пользователя через SRS и вызывает настроенный в приложении LLM. При изменении исходников страница InsightBook перезагружается; текущая игровая сессия при этом начинается заново.

1. В первом терминале из корня монорепозитория запустите:

   ```bash
   bun run --filter @injurka/insight-book-plugin-detective-case dev
   ```

2. Откройте dev-страницу `http://127.0.0.1:5179/dev.html`. Она покажет адрес манифеста и статус HMR.

3. В InsightBook откройте **Настройки → Плагины → Добавить по URL** и укажите URL манифеста `http://127.0.0.1:5179/manifest.json`.

4. На вкладке **Установленные** убедитесь, что переключатель Detective English включён. Установка по URL включает плагин автоматически.

5. Чтобы запустить игру, закройте настройки плагинов. Detective English появится отдельной карточкой в секции **Режимы тренировки** настроек SRS. Также игру можно открыть из меню аккаунта/шестерёнки справа вверху.

Для генерации нужны доступные в SRS английские слова с русским переводом и настроенный LLM-провайдер.

Dev-сервер должен оставаться запущенным, пока плагин используется.

### Production-сборка

```bash
bun run --filter @injurka/insight-book-plugin-detective-case typecheck
bun run --filter @injurka/insight-book-plugin-detective-case lint:fix
bun run --filter @injurka/insight-book-plugin-detective-case build
bun run --filter @injurka/insight-book-plugin-detective-case pack
```
