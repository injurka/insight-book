# Павильон загадок

Да-нетка для InsightBook: хранитель загадывает одно существительное из текущей очереди SRS, игрок исследует его свойства и вспоминает написание на языке карточки. Отдельная полноэкранная страница, вход из меню и списка тренировок словаря. Интерфейс на русском; карточки поддерживают en, zh, ja, ru, вопросы — любой язык, понятный выбранной LLM.

## Игровой цикл

1. Выберите язык и проверьте очередь. Берутся только карточки, уже назначенные к повторению; будущие карточки не подмешиваются.
2. LLM проверяет часть речи именно в значении перевода карточки. Неоднозначные слова, собственные имена и неподходящие для вопросов значения пропускаются. Существительные с ясным абстрактным значением допустимы. Очередь сортируется по сроку повторения. Само слово до конца раунда скрыто.
3. За 20 ходов задавайте отдельные вопросы о свойствах. Ответы: да / нет / отчасти / неясно. «Верный след» — качественный ориентир. Можно открыть три подсказки или закончить раунд раскрытием ответа.
4. Переключитесь на «Назвать слово» и введите слово на языке карточки. Победу проверяет код по написанию, а не LLM. Регистр, NFKC, пунктуация и начальный английский артикль не мешают; синонимы, переводы, опечатки и другие словоформы не заменяют изучаемое слово. Если AI узнаёт смысл перевода, он предложит вспомнить само слово.
5. Выберите оценку знания слова для SRS (1–4) либо завершите без записи. Вопросы, подсказки и победа сами по себе расписание не меняют.

## Установка и запуск

Из корня монорепозитория:

```sh
bun install
bun run --filter @injurka/insight-book-plugin-lotus-riddle dev
bun run --filter @injurka/insight-book-plugin-lotus-riddle pack
```

- Демо: `http://127.0.0.1:5180/`. Его ответы заранее подготовлены, API и SRS заменены моками; баннер явно сообщает об этом. Демо-слово — `lantern`. `?empty=1` показывает пустую очередь, `?ai-error=1` — недоступную модель. Эти режимы удобнее открывать в новой вкладке, поскольку текущая вкладка восстанавливает незавершённый раунд.
- Для реальной игры в InsightBook: Настройки → Плагины → Добавить по URL → `http://127.0.0.1:5180/manifest.json`. Нужны настроенная LLM и существительные в очереди повторения.
- ZIP: `lotus-riddle-v1.0.0.zip` в каталоге пакета. Готов для загрузки в каталог. Публикация и установка не выполняются сборкой.
- Маршрут в хосте: `/plugin/lotus-riddle`; expose — `./Plugin`.

## Архитектура и ограничения

Плагин использует только фасад `ctx.api`: `dictionary.getDueWords`, `dictionary.submitGrade`, `llm.generate`, `user.getProfile`. Сторы приложения не импортируются. Очередь, оркестрация и сохранение отделены от компонентов; все ответы LLM проходят проверку контракта. Неполный список частей речи отклоняется целиком. Классификация неизменных карточек кэшируется на время открытой страницы, чтобы не оплачивать её заново после каждого раунда. Новая очередь SRS запрашивается между раундами. Текущий API хоста возвращает максимум 50 самых ранних карточек; существительные вне этой порции станут доступны после повторения предыдущих карточек в словаре.

Факты и смысл фиксируются при создании загадки. Для вопросов отображаются только проверенные перечисления, без свободного текста модели; AI не может объявить победу. Вступление и подсказки проверяются на буквальное раскрытие слова/перевода. Это не полная морфологическая или смысловая защита: качество классификации, намёков и ответов зависит от выбранной модели. Промпты обозначают пользовательский ввод как данные. Ответ хранится на клиенте и не защищён от просмотра через инструменты разработчика: это учебная игра, без соревновательной экономики.

Повтор одинакового нормализованного хода не вызывает LLM и не расходует ход. Ошибка сети/JSON не добавляет ход и оставляет введённый текст. Сетевые операции имеют таймаут; ответы после ухода со страницы не применяются. Фасад генерации не поддерживает AbortSignal: таймаут ограничивает ожидание интерфейса, но не гарантирует отмену запроса на сервере. Лимиты и оплата модели остаются настройками InsightBook.

Раунд хранится в `sessionStorage` до 12 часов бездействия, отдельно для id текущего пользователя. При отсутствии профиля или доступного хранилища игра продолжает работать и сообщает, что восстановление недоступно. Хранилище не синхронизируется между устройствами. Запись оценки блокируется сразу перед запросом; при потере подтверждения или перезагрузке во время отправки состояние становится «не подтверждено», автоматических и ручных повторов в этом раунде нет. Глобальная гарантия однократности между несколькими вкладками/устройствами требует idempotency key в API хоста, которого сейчас нет. При параллельном повторении одной карточки проверяйте её в словаре.

Полноэкранный режим без блокировки ориентации. На узком экране журнал и ввод идут раньше подсказок. Клавиатура: Enter отправляет ход, Shift+Enter добавляет строку; незавершённая IME-композиция не отправляется. Раскрытие требует подтверждения в диалоге, Escape закрывает его. Элементы имеют подписи, состояния disabled и видимый фокус; результат получает фокус. Переполнение журнала прокручивается отдельно, вся страница допускает прокрутку на небольших экранах. Анимации, таймеры и автозвуки не отвлекают от игры.

## Оформление и ассеты

Концепция: вечерний павильон лотоса, резное ореховое дерево, янтарные фонари, бумажный журнал и три лепестка подсказок. Декоративный фон не содержит текста; интерфейс — живые доступные элементы. Изображение предварительно декодируется, гейт имеет таймаут и при ошибке оставляет однотонный фон. Локальная иконка меню регистрируется без обращения к Iconify CDN. Сборка использует относительные пути ассетов и `bundleAllCSS: true` для загрузки с адреса remote.

Фон `src/assets/pavilion.png` создан встроенным imagegen. Полный использованный промпт сохранён в [ART-PROMPT.md](ART-PROMPT.md). Отображение — `image-rendering: pixelated`; генеративная иллюстрация не является математической гарантией единой пиксельной сетки на всех размерах окна.

## Проверки

```sh
bun run --filter @injurka/insight-book-plugin-lotus-riddle lint
bun run --filter @injurka/insight-book-plugin-lotus-riddle typecheck
bun test packages/plugin-lotus-riddle/src
```

Тесты проверяют очередь, омонимы, часть речи, повреждённые ответы AI, утечку ответа, написание догадки, восстановление отправляемой оценки, изоляцию аккаунтов и повреждённое/недоступное хранилище. Браузерное демо проверяет интерфейс и переходы, но не подтверждает ответы реальной модели или фактическое обновление SRS на сервере.
