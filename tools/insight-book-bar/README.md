# InsightBook в панели end-4

Кнопка SRS для Quickshell `ii`. В вертикальной панели находится сверху под значком end-4; в горизонтальной — рядом с системным треем. Popover использует шрифты, цвета и компоненты текущей темы.

## Установка

Из корня репозитория:

```sh
python3 tools/insight-book-bar/install.py
```

Нужны Quickshell, Python 3 и `xdg-open` для входа через Яндекс. Дополнительные Python-пакеты не требуются. Установщик сохраняет резервные копии изменяемых файлов в `~/.config/quickshell/ii/scripts/insightBook/backups/`, сохраняет остальные настройки и запускает штатную перезагрузку конфигурации через изменение QML. Повторный запуск обновляет компоненты без дублирования кнопки.

Для другого расположения `ii`:

```sh
python3 tools/insight-book-bar/install.py --shell /path/to/quickshell/ii
```

После обновления end-4, если оно перезаписало панель, запусти установщик снова.

## Подключение и повторение

1. Нажми кнопку карточек в панели. При первом запуске откроются настройки.
2. Адрес по умолчанию: `https://insight-book-api.limited-dissolve.ru`.
3. Войди по логину/email и паролю либо через Яндекс в браузере. Для сервера в режиме `single` достаточно применить настройки.
4. Укажи язык (`all`, `en`, `zh` и т. п.), язык перевода (`ru`) и колоду. Нажми «Применить настройки». Кнопка шестерёнки возвращает к карточкам.
5. Раскрой перевод, затем оцени карточку: «Снова», «Трудно», «Хорошо» или «Легко».

Горячие клавиши внутри popover: **Пробел** раскрывает перевод, **1–4** отправляют оценку после раскрытия, **Esc** закрывает окно. Кнопка обновления заново загружает очередь. Фоновое обновление работает раз в минуту, когда popover закрыт.

Можно открыть popover через IPC, указав имя монитора:

```sh
qs -c ii ipc call insightBook open DP-1
qs -c ii ipc call insightBook status
```

Оценки сохраняются через существующий `POST /api/dictionary/review`. FSRS на сервере определяет следующий срок. Карточка убирается из локальной очереди только после подтверждения сохранения. При сбое отправки обнови очередь перед повторной оценкой; автоматического повтора POST нет.

## Сессия и счётчик

Настройки и токен хранятся в `$XDG_CONFIG_HOME/insight-book-bar/settings.json` (обычно `~/.config/insight-book-bar/settings.json`): каталог `0700`, файл `0600`. Пароль не сохраняется и не передаётся через аргументы команд. Токен не выводится в ответах помощника, логах или IPC. При смене адреса сервера сессия сбрасывается. Удалённые серверы требуют HTTPS; HTTP разрешён только для localhost. «Выйти из аккаунта» удаляет сохранённую сессию.

Новый `GET /api/dictionary/review/count` возвращает `{ count }` для всех слов с наступившим сроком, с фильтрами `language`/`lang`, `targetLang`, `deckId`, `difficulty` и той же авторизацией, что очередь. Лимит карточек очереди остаётся 50. Ответ счётчика запрещает кеширование.

Пока этот маршрут не опубликован на беке, при HTTP 404 помощник использует существующий `/api/dictionary/` и считает все подходящие слова локально. Это даёт полный счётчик, но загружает весь словарь. Виджет работает с текущим сервером без обязательного деплоя. После публикации маршрута автоматически использует компактный ответ счётчика.

## Проверка

```sh
python3 -m unittest discover -s tools/insight-book-bar -p 'test_*.py' -v
bun test apps/server/src/repositories/dictionary.repository.test.ts apps/server/src/controllers/dictionary.controller.test.ts
```

Python-тесты запускают временный HTTP API на localhost и проверяют авторизацию, хранение сессии, очередь более 50 слов, совместимость старого счётчика, сохранение оценок и сбой обновления после успешной записи. Пользовательский сервер и его слова в этих тестах не используются.

## Удаление кнопки

```sh
python3 tools/insight-book-bar/install.py --remove
```

Команда удаляет только добавленные блоки кнопки и импорты из обеих панелей. Резервные копии и настройки сохраняются. Для удаления токена сначала выйди из аккаунта в виджете.
