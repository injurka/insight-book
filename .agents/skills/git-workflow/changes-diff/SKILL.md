# Changes Diff & Merge Request Summary Workflow

Этот скилл автоматически анализирует изменения текущей ветки относительно целевой ветки (`master` или `main`), генерирует детальный разбор и сохраняет результат в файл `changes-diff.md` в корне проекта.

## Порядок действий

1. **Сбор данных из Git:**
   - Определи текущую ветку:
     ```bash
     git branch --show-current
     ```
   - Определи целевую ветку (`master` или `main`):
     ```bash
     git rev-parse --verify master >/dev/null 2>&1 && echo "master" || echo "main"
     ```
   - Получи список коммитов и их хеши:
     ```bash
     git log <target-branch>..HEAD --oneline
     ```
   - Получи авторов изменений:
     ```bash
     git log <target-branch>..HEAD --format="%an" | sort -u
     ```
   - Получи общую статистику (количество файлов, добавленных и удаленных строк):
     ```bash
     git diff --shortstat <target-branch>..HEAD
     ```
   - Получи список измененных файлов с локальной статистикой (+/- строк):
     ```bash
     git diff --numstat <target-branch>..HEAD
     ```
   - Прочитай полный diff для анализа сути изменений:
     ```bash
     git diff <target-branch>..HEAD
     ```

2. **Анализ изменений:**
   - Определи верхнеуровневую цель задачи/фичи.
   - Сгруппируй и проанализируй файлы по слоям (например, `01.kit`, `04.features`, `apps/server`, парсеры и т.д.).
   - Сформулируй краткую и емкую суть изменений для каждого файла.
   - Выдели наиболее важные диффы/куски кода, отражающие суть рефакторинга или новых функций.

3. **Запись файла `changes-diff.md`:**
   Сформируй и сохрани файл `changes-diff.md` в корне проекта по следующему шаблону:

```markdown
# Merge Request: `<current-branch>` → `<target-branch>`

**Ветка:** `<current-branch>`  
**Коммиты:** `<count>` (`<short-hash-1>`, `<short-hash-2>`, ...)  
**Автор:** `<author-names>`  
**Файлов изменено:** `<files-count>` (+`<added-lines>` строк, −`<deleted-lines>` строк)
